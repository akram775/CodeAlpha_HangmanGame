CodeAlpha Hangman Game

Project Description
This is a simple text-based Hangman Game developed using Python as part of the CodeAlpha Python Programming Internship.

Features
•	Random word selection from 5 predefined words.
•	Maximum 6 incorrect guesses.
•	Letter-by-letter word guessing.
•	Duplicate letter detection.
•	Invalid input handling.
•	Win and Game Over conditions.

Technologies Used
•	Python
•	Random Module
•	Lists
•	Loops
•	Conditional Statements

How to Run

•	Install Python.
•	Download or clone this repository.
•	Open the project folder in VS Code.
•	Run the following command:

```bash
python main.py
```
